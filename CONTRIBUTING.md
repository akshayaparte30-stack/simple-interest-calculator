# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

## Contributions

All contributions are welcome, including:
- Bug reports
- Bug fixes
- Documentation improvements
- Enhancements
- New ideas and suggestions

## How to Contribute

1. Fork this repository.
2. Create a new branch.
3. Make your changes.
4. Test your changes.
5. Submit a Pull Request describing your contribution.

## Reporting Bugs

Please provide a clear description of the issue and steps to reproduce it.

## Suggestions

We welcome ideas that can improve the project.

Thank you for helping improve this project!
