# Simple Interest Calculator

## Project Description
This project explains how to calculate simple interest using principal amount, rate of interest, and time.

## Formula
Simple Interest = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Rate of Interest
- T = Time (in years)

## Example
Principal = 1000  
Rate = 5%  
Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100

**Output: 100**

## Features
- Calculates simple interest.
- Easy to understand.
- Uses a basic mathematical formula.
